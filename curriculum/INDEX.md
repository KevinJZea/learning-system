# Curriculum Index

Router for the learning system. Keep this skimmable. Deep content lives in `topics/<slug>.md`.

## How to use

- **Session start:** read this file with `PROFILE.md` and `progress.md`
- **Teaching a topic:** open `topics/<slug>.md` if it exists
- **New topic:** copy `templates/topic.md` → `topics/<slug>.md`, then add a row here
- **Suggested next:** prefer gaps that unlock AI Engineering + backend/systems breadth (see PROFILE)

## Suggested learning paths (high level)

Not a rigid syllabus—use as orientation. Adjust from progress and interest.

### Path A — Systems foundation (supports everything)

1. HTTP, networking basics, processes/OS mental model
2. Backend fundamentals (APIs, auth, data modeling)
3. Databases (relational + when to use others)
4. Docker and runtime isolation
5. Cloud fundamentals (regions, compute, storage, IAM)
6. System design & architecture tradeoffs
7. Distributed systems essentials (consistency, queues, caching)

### Path B — Toward AI Engineering

1. Python fluency for engineering (beyond intro)
2. Data fundamentals (pipelines, quality, storage)
3. ML mental models (training vs inference, eval)
4. Applied LLM systems (prompts, RAG, tools, evals, cost/latency)
5. Production AI (observability, safety, versioning, architecture)

### Path C — Quality & delivery

1. Testing strategies
2. CI/CD mental model
3. Observability
4. Security basics for app engineers
